# 浪白漫画字幕工坊 1.3.0：操作指南

## 当前状态与界限

这是 1.3.0 的功能使用指南。源码实现、单项自动测试、Web 构建、安装版运行和手机实机使用是不同层次的证据；未验证的层次不能写成已经完成。安装包与在线体验以正式发布记录为准，真机和性能验证边界见本文末尾。

桌面工作台由图片队列、画布、章节文本/多选入口、属性区和独立导出入口组成。手机竖屏使用底部导航和属性抽屉，横屏利用左右区域。布局、触摸选中、输入法和系统文件权限需要分别实测。

## 一、建项目，确认顺序

1. 在项目页新建项目，名称留空时采用时间命名。
2. 添加图片，确认默认名称自然排序和最终顺序。默认排序后仍可人工调整。
3. 核对原图像素尺寸。每个 `[图片 N]` 对应确认顺序中的第 N 张，文件名只是人工核对信息。
4. 进入画布编辑。缩略图、画面缩放与字幕原图坐标是不同概念，不要按屏幕预览尺寸重新计算脚本矩形。

## 二、选中与文字编辑

- 点击气泡、纯文字或图片元素显示调整框；点击画布空白取消选中，不删除对象。
- “添加文字”创建无框文字。调整框只是编辑辅助，不应进入成图；正文仍可拖动、调整排版区域及文字样式。
- 属性区修改正文、字体、颜色、字号模式、行距、字距、对齐和文字描边。实时预览不应打断输入焦点或输入法组合。
- 文字描边和气泡边框分开设置。纯文字可添加文字描边，但没有气泡底色、外框或尾巴。
- 心理与对话气泡的尾巴维持固定角向，不像独立图片元素一样任意拖动。

## 三、固定字号与自动适应

**固定字号为新建对象默认方式**：设置的字号是排版依据，拉框只改变可用区域，不自动缩字。框过小时显示超框警告，先扩大安全区域、缩短台词、调整行距或主动修改字号。

固定字号不表示全项目只能使用同一字号。每个对象可独立设置，也可通过批量属性或文字样式保持一致。

**自动适应要主动选择**：文字为矩形拟合字号，属性区显示设定字号和实际字号。实际字号过小仍应调整排版，不能因为全部放进框内就认为可读。

作品正文必须完整保留。与正文不同，侧栏摘要和字体样本可能为界面预览使用省略显示，不是导出内容。

## 四、多选、应用范围与样式关联

在章节文本列表中定位对象或勾选对象，再选择批量应用范围：当前图片、已勾选对象、整个章节。随后勾选真正需要应用的属性，未勾选的属性应保持不变。应用反馈应说明范围和处理对象数量。

命名的关联文字样式用于维护多个对象共同的字体、字号、颜色等。修改关联样式会同步其他关联对象；只想改一个对象时，先解除关联。正文和矩形位置不应因共用文字样式变得相同。

关联样式不是此前移除的固定比例气泡预设；它解决一致性维护，而不是增加一些用户本来可以手动调出的外观按钮。

## 五、本地字体库

| 分类 | 内置字体 |
| --- | --- |
| 黑体 | 思源黑体 / Noto Sans SC |
| 宋体 | 站酷小薇、思源宋体 / Noto Serif SC |
| 楷体 | 霞鹜文楷 / LXGW WenKai |
| 漫画、标题 | 站酷快乐体、站酷庆科黄油 |
| 书法、手写 | 马善政毛笔、刘建毛草、龙藏体、知芒行 |

十种内置字体均使用完整本地字体文件，来源、SHA256 与随附许可记录在 [字体清单](../assets/fonts/fonts_manifest.json)。字体按需读取注册，不在启动时一次加载全部字体，不使用在线字体 CDN。

字体库支持搜索显示名称、内部名称、文件名和分类；可收藏、查看最近使用，并用当前字幕查看真实字体预览。

使用“批量导入”选择多个独立 TTF/OTF 文件。显示名称来自字体名称表，素材身份为完整内容的 SHA256 加 face0；相同内容改名后复用。第一版不导入 TTC 集合和 WOFF/WOFF2，改文件后缀不能将无效文件变成字体。

**缺字体**表示资源找不到、损坏或不能载入；**缺字**表示字体存在但缺少正文所需字符。缺字体时保留原身份、提示临时替代；选择正式替换后才更改工程样式。缺字要检查具体字符，而不是只看字体名称是否存在。

用户导入字体复制到当前设备全局库，工程需要时保存字体资源；仅导出 BCS 不包含字体字节。跨设备继续编辑时优先备份完整工程。导入前确认许可允许使用、嵌入和必要的再分发，“可商用”不自动等于“可随工程或安装包分发”。

## 六、字幕窗口是草稿

打开字幕窗口后编辑草稿。取消不修改工程，确认应用才成为当前预览、保存和导出的对象内容。

稳定 `@气泡ID` 用于合并。这次只改台词，不应把已有手工矩形重新排一遍；只改字号，不应覆盖未修改的字体、颜色和其他样式。需要重置位置时使用明确的排版操作。

### BCS v3

默认导出 v3，保留图片段、气泡 ID、矩形及基本样式，并增加：

- `@字号模式=固定` 或 `@字号模式=自动适配`；
- `@文字描边`、`@文字描边颜色`；
- `@字距`、`@对齐`；
- 适用时的字体素材 ID 和关联样式 ID；
- `@正文行数`，之后精确数量的行作为作品正文。

正文行数包括正文空行。属于声明正文的冒号、`@`、`#`、`[图片 N]` 等必须作为作品文字读取，不能重新当作角色标签或脚本指令。人工修改时，正文行数和实际正文必须一致。

### 读取旧版与 v2 兼容导出

继续读取 v1/v2；v2 没有明确记录的字号模式按兼容自动适应处理。选择 v2 导出前会提示属性损失：固定字号模式、文字描边、字距、对齐、字体素材身份和样式关联等不能完整往返。

正文空行、特殊开头、空气泡或首尾空白也不要依赖 v2 无损备份。继续精确编辑时保留 v3 与完整工程。BCS 文本仍不包含图片元素。

## 七、保存、撤销与版本历史

- **自动保存**：编辑停止后发起提交，等待保存或正在保存不是已经落盘。失败应可见，修改不因失败清空。
- **手动保存**：主动提交当前修订，等待明确结果，失败可重试。
- **撤销/重做**：操作当前编辑会话历史；连续文字输入可以作为一组回退，不等同于从磁盘恢复旧工程。
- **保存版本历史**：查看近期已经成功提交的版本，恢复会成为新修订并应允许撤销恢复操作；不能恢复尚未提交的输入。
- **完整工程备份**：将工程另存到用户指定位置，用于迁移或独立备份，本地保存版本不能代替外部备份。

打开另一份工程前先提交当前修改；导入工程创建为新项目，不用当前项目 ID 覆盖原项目。原项目保留在项目页，可切换回来。

软件闪退、断电或系统强制终止时，以最后成功提交版本为恢复依据。不承诺保住所有仍在内存、尚未提交的输入。重要修改后确认成功保存，定期导出完整工程。

## 八、导出、取消和重试

1. 在右上角批量导出中勾选图片。
2. 阅读技术预检，包括缺字、缺字体、超框或几何异常。返回调整，或明确知悉可能出现问题后选择继续。
3. 确认目录或浏览器下载方式，按本次快照逐张渲染，查看进度和目标位置。
4. 同名文件选择跳过、覆盖此图、全部覆盖或取消。文件已存在不等于当前修订已经导出。
5. 取消在文件处理边界生效，此前已写出的图片保留，不自动撤销整个批次。
6. 检查成功、跳过和失败清单，需要时重试失败图片。若工程随后改动，重试前重新确认当前内容。

浏览器回退下载只表示交给浏览器，不能证明用户目录已经收齐。检查下载记录；必要时允许本站点多文件下载，或使用逐图保存列表。

PNG 是合成结果，不能靠它恢复可编辑文字层；完整工程保存结构，BCS 保存可记录的字幕与排版数据，三者用途不同。

## 九、发布和设备验证

本次发布不代替真机验收。仍需分别验证 Windows Setup 安装后运行和内更新、Android/iOS 文件选择与字体导入、手机竖横屏触摸和输入法、macOS/Linux 运行依赖，以及 Web 本地存储重载和浏览器导出。

自动测试不等于手机实机测试，Web 运行不等于 Electron 安装版运行，更新清单也不等于软件内下载与安装更新已通过。iOS 未签名 IPA 需要重新签名，不能作为普通用户即装即用或已上架的证据。

实际观察结果登记在 [设计与交互验证记录](../design-qa.md)。本指南不预填测试数量或“全部通过”结论。

### Web 文件夹权限受限时
在图片导出选择窗点击“直接逐图下载”，不必申请目录权限。若浏览器阻止多文件下载，可在结果窗口打开“逐图保存列表”逐张保存；下载发起不等于已经写入磁盘。

批量应用也可选择“指定多张图片全部对象”，在独立图片选择窗勾选任意页；要细化到对象则使用章节文字中的对象勾选范围。
