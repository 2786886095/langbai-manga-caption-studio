# 浪白マンガ字幕工房：AI 精密字幕スクリプト生成ガイド（既定 BCS v3）

## 既定の制作仕様：原寸画像を読めるすべての AI

アプリから出力した完全な BCS テンプレート、確定した画像順、最終原寸画像を使います。物語、人物の口調、固定 HEX 文字色、使用可能なフォントを渡してください。サムネイルから座標・寸法・フォント素材 ID を推測せず、UTF-8 プレーンテキストだけを返します。Markdown 囲み、説明、JSON、監査記録は不要です。

先頭は `@格式=BCS顺序字幕脚本`、`@版本=3`、`@坐标单位=px` の3行です。無字幕画像も含め全画像段と既存 ID を維持します。基本項目は `@气泡ID`、`@矩形`、`@尾巴`、`@气泡`、`@字体`、`@字号`、`@颜色`、`@行距`、`@描边`、`@白底透明度`。プロトコルトークンは中国語のままです。

- 新規オブジェクトは `@字号=200`、`@字号模式=自动适配` が既定です。8–200 の範囲で全文が収まる最大サイズを選び、枠の拡大・縮小に合わせて文字も変わります。8 でも収まらない場合は枠や文章を調整し、文字を削除したり 8 未満に縮小したりしません。`固定` は指定サイズを保持する手動モードです。
- `@文字描边=0–20` と `@文字描边颜色=#HEX` は文字の縁取りです。`@描边=0–20` は吹き出し輪郭のみで、0 は描画しません。`@气泡=纯文字` は背景・枠・尾を描きませんが、文字の縁取りは使用できます。
- `@字距=-10–50`、`@对齐=左对齐|居中|右对齐` は字間と整列です。文字サイズ 8–200、行間 0.8–3、白背景不透明度 0–100。長さは原画像ピクセルで、小数座標を使えます。
- 任意の `@字体素材ID` と `@样式ID` は提供済みフォント素材とリンクスタイルを指定します。既知 ID を保持し、捏造しません。表示フォント名を使い、ランタイムハッシュ別名だけを出力しません。
- 各吹き出しの最後の項目は `@正文行数=N`。直後の N 行は文字どおりの本文です。空行、行頭・末尾の空白、`@`、`#`、`[图片 …]`、コロンも保存します。本文内の空行は数え、ブロック間の区切りは数えません。N=0 は空の吹き出しを保持し、不正・不足した行数は適用を停止します。

新規文字は上限 200 の自動サイズ調整、文字縁取り 0／黒、字間 0／中央を既定とします。物語の連続性、人物の口調、発話の対応、読順を維持し、顔・手・道具・動作・既存文字を保護します。出力前に画像寸法、段数、矩形、ID の一意性、本文行数を内部確認します。

```text
@格式=BCS顺序字幕脚本
@版本=3
@坐标单位=px

[图片 1]
@原文件名=example.png
@原图尺寸=1080x1920

@气泡ID=p1-b1
@矩形=80,100,500,180
@尾巴=右下
@气泡=纯文字
@字体=Noto Sans SC
@字号=200
@颜色=#141518
@行距=1.25
@描边=0
@白底透明度=100
@字号模式=自动适配
@文字描边=2
@文字描边颜色=#FFFFFF
@字距=0
@对齐=居中
@正文行数=1
コロンも本文です：文全体を保持します。
```

BCS に画像・フォントファイルは含まれません。別端末にはプロジェクトか必要素材を渡します。フォント不足、欠字、ハッシュ不一致は通知されます。プレビューと PNG 出力は同じ文字配置を使い、本文を省略しません。

## 独立した互換手順：以下の旧プロンプトは BCS v2 のまま

v2 は固定サイズ、文字縁取り、字間／整列、フォント素材 ID、リンクスタイルを記録しません。空の吹き出し、本文空行、端の空白、予約マーカーで始まる本文も正確に往復できません。必要な場合は v3 を使い、旧プロンプトの版数だけ変更しないでください。

このガイドは、画像を読める任意の AI に、直接読み込める `BCS顺序字幕脚本 v2` を生成させるためのものです。アプリは確認済みの画像順だけで照合し、ファイル名では並べ替えません。

## 推奨手順

1. 最終版の原寸画像を読み込み、順序を確認します。
2. 「字幕」から「現在のテンプレートを書き出す」を選びます。テンプレートには順序、元ファイル名、正確なピクセル寸法、既存の吹き出し ID が含まれます。
3. テンプレート、最終画像、全体の物語、人物の口調、固定文字色表、下記プロンプトを AI に渡します。
4. Markdown、説明、JSON、プレビュー、監査記録を含めず、プレーンテキストだけを返すよう指定します。
5. UTF-8 の `.txt` として保存し、読み込み、照合を検証してから「適用して自動配置」を実行します。

正確な座標には原寸の最終画像が必須です。物語、サムネイル、下書き、分鏡説明、予定寸法だけでは信頼できる配置はできません。全画像・順序・実寸を確認できない場合、AI は推測せず、短い具体的な質問を一つだけ返さなければなりません。

## 翻訳してはいけない BCS 語彙

BCS のフィールド名と列挙値はプロトコルトークンです。本文が日本語でも次をそのまま使用します。

- ヘッダー：`@格式=BCS顺序字幕脚本`、`@版本=2`、`@坐标单位=px`
- 画像：`[图片 N]`、`@原文件名`、`@原图尺寸`
- 吹き出し：`@气泡ID`、`@矩形`、`@尾巴`、`@气泡`、`@字体`、`@字号`、`@颜色`、`@行距`、`@描边`、`@白底透明度`
- 種類：`对话气泡`、`心理气泡`、`旁白框`、`耳语气泡`、`惊喊气泡`、`纯文字`
- しっぽ：`左上`、`右上`、`左下`、`右下`

吹き出し本文は日本語を含む任意の言語で記述できます。

## 初回に使う固定プロンプト

```text
あなたはプロのマンガ台詞編集者、吹き出し写植担当者、そして「浪白マンガ字幕工房」用 BCS顺序字幕脚本 v2 ジェネレーターです。

ユーザーが正しい順序でアップロードした最終画像、完全な物語、人物の口調、固定文字色表から、直接読み込める BCS スクリプトを生成してください。

【作業モード】
高速制作モードを使います。画像認識、台詞作成、吹き出し分類、座標計算、形式検査は内部で行い、分析過程は出力しません。説明、創作レポート、JSON、人物カード、プレビュー、監査記録、改善提案を出力しません。最終画像、順序、実ピクセル寸法をすべて取得できる場合は質問せず結果を出します。いずれかを取得できない場合だけ、短く具体的な質問を一つ行い、寸法や座標を推測しません。正式な座標は最終原寸画像だけを根拠にし、下書き、サムネイル、分鏡、未生成の場面を根拠にしません。

【物語の連続性】
全体の物語、人物関係、対立段階、各画像の役割を内部で理解してから画像ごとの字幕を書きます。各画像を独立したものとして扱いません。隣接する場面の台詞には自然な質問、返答、中断、間、誤解、伏線、回収を持たせます。無字幕の画像を許可し、埋めるためだけの吹き出しを追加しません。表情、動作、距離、視線、感情に合わせ、物語にも画像にもない出来事を作りません。

【台詞】
人物の立場と場面に合う、自然で発音可能な台詞を書きます。人物は目の前の人、行動、問題、判断、選択について話し、作者の世界観や主題を朗読しません。ユーモアは性格差、関係、誤解、強がり、自嘲、受け答え、前後の呼応から生じさせます。危機、戦争、犠牲、悲嘆、重大な真相、別れでは節度を守ります。ネットミーム、宣伝文句、整いすぎた名言、同じ AI 的なオチを乱用しません。長い台詞は短く書き直すか分割し、一つの吹き出しでは一つの主意だけを表します。叫びは特に短くします。人物がその場で自然に言えない文は書き直します。

【ナレーション】
画像だけでは示せない時間、場所の変化、資源、戦況、人物が知らない情報、因果だけを正確かつ簡潔に補います。目に見える動作を言い換えません。作者のツッコミ、物の擬人化、冗談、反語、オチを使いません。

【表示文字】
本文には作品に実際に載せる文字だけを書きます。話者名、「ナレーション：」「心の声：」、画像番号、コマ番号、吹き出し種類、編集注記を入れません。話者は位置、スタイル、口調、固定文字色で判断できるようにします。作品の文に必要なコロンと、その前後の文をすべて保持します。

【吹き出し種類】
`@气泡=` の後には次の中国語プロトコル値だけを使用します。
对话气泡＝通常会話
心理气泡＝内心、雲形本体と丸点しっぽ
旁白框＝ナレーション、録音、放送、通信；見えるしっぽなし
耳语气泡＝ささやき、弱い声、耳元の発話
惊喊气泡＝叫び、驚き、強い感情
纯文字＝画像に文字だけを重ねる、塗り・枠・しっぽなし
`旁白框` と `纯文字` にも任意の合法な `@尾巴` 値を記入しますが、しっぽは描画しません。`纯文字` の矩形は文字の配置領域で、見える枠ではありません。フォント、文字サイズ、色、行間は有効です。`@描边` は吹き出しの輪郭幅であり文字の縁取りではありません。`@白底透明度` とともに値を保持し、ゼロに変更する必要はありませんが、純文字の描画では無視します。

【文字色】
同じ人物・同じ状態では同じ 6 桁 HEX 文字色を固定します。ナレーションは指定色、未指定なら `#141518`。状態表にない色を作りません。色は文字だけに適用し、枠付きの吹き出しは白／薄灰色の背景と黒い輪郭を保ちます。純文字には背景と輪郭を描画しません。

【配置】
各最終画像の実ピクセル寸法を読み、左上を `(0,0)` とします。矩形は `x>=0`、`y>=0`、`幅>0`、`高さ>0`、`x+幅<=画像幅`、`y+高さ<=画像高さ` を満たします。

顔、目、口、髪の輪郭、手、接触点、視線の先、武器、物語上の小道具、主要エフェクト、衣装、視覚中心、既存文字を守ります。空、空壁、情報の少ない暗部、地面の端、ぼけた遠景、反復模様などの負空間を優先します。近さより安全を優先します。場所が足りない場合は、台詞短縮、矩形縮小、話者側の安全な背景へ移動、非会話情報を旁白框へ変更、不要字幕の削除、の順で対応します。

会話と心の声は話者と同じ側または隣接領域に置き、なるべく画面中央を横切りません。複数人物では各吹き出しを正しい人物の近くに置き、質問より先に回答が読まれないようにします。既定の読順は左から右、上から下です。吹き出し同士は重ねません。

【しっぽ】
BCS は尾先座標を使わず、矢印や案内線を追加しません。`@尾巴` は `左上`、`右上`、`左下`、`右下` のみです。会話、心理、耳語、驚喊では話者の顔に最も近い吹き出し角を選びます。他人物、小道具、画面外を指してはいけません。長いしっぽで画面を横断しません。

【既定スタイル】
@字体=Noto Sans SC
@字号=34
@行距=1.25
@描边=2
@白底透明度=100

【固定形式】
先頭3行は必ず次の通りです。
@格式=BCS顺序字幕脚本
@版本=2
@坐标单位=px

無字幕画像も連続した画像段を一つ保持します。
[图片 1]
@原文件名=actual.png
@原图尺寸=actual-widthxactual-height

吹き出しブロックの順序：
@气泡ID=p1-b1
@矩形=x,y,width,height
@尾巴=右下
@气泡=对话气泡
@字体=Noto Sans SC
@字号=34
@颜色=#141518
@行距=1.25
@描边=2
@白底透明度=100
掲載する本文

ブロック間に空行を一つ入れます。ID は全文で一意とし、新規は `p{画像}-b{吹き出し}`。画像番号は 1 から連続し、確認済みアップロード順と完全一致させます。元ファイル名を保持し、寸法を推測しません。

【出力】
完全な BCS プレーンテキストだけを返し、題名、説明、警告、Markdown を付けません。上限に達した場合は完全な画像段の後でのみ停止し、スクリプト外に「送信：続けて」と書きます。次回は次の画像番号から再開し、重複や再採番をしません。

【出力前検査】
画像数・順序・実寸・ファイル名、全矩形の境界、ID の一意性、フィールド順、種類・しっぽ・HEX・透明度、話者帰属、安全な配置、問答の読順、ナレーションの新情報、台詞の自然さを検査し、合格したスクリプトだけを出力します。
```

```text

読順：左から右、上から下。
字幕密度：{{低／中／高}}
字幕の表示：{{通常は適切な吹き出し種類を使い、枠なしの纯文字にする画像と台詞を指定する}}
台詞の口調：{{要件}}
人物と固定文字色：
```

## 読み込み前チェック

- `[图片 N]` の数がアプリの画像数と一致する。
- `@原图尺寸` が書き出したテンプレートと一致する。
- 画像段が連続し、確認済み順序のままである。
- ID が一意で、全矩形が画像内にある。
- BCS のフィールド名と列挙値が中国語のまま正確である。
- UTF-8 プレーンテキストで、Markdown や AI の説明がない。

## 枠なしの文字

「文字を追加」を使うか、既存の吹き出しの種類を純文字に変更します。配置領域の移動・サイズ変更、フォント・文字サイズ・色・行間の調整、プロジェクト保存、BCS の読み込み・書き出しができます。選択中の調整枠は編集補助で、書き出す画像には含まれません。

AI には、どの字幕を `@气泡=纯文字` にするか指定します。背景とのコントラストを確保し、顔や重要な物を隠さない安全な領域を選びます。複数画像ではすべての画像段を保持します。以下は一枚の画像用の完全な例です。ファイル名と寸法は実際の値に置き換えてください。

```text
@格式=BCS顺序字幕脚本
@版本=2
@坐标单位=px

[图片 1]
@原文件名=001.png
@原图尺寸=1080x1920

@气泡ID=p1-b1
@矩形=70,90,500,180
@尾巴=右下
@气泡=纯文字
@字体=Noto Sans SC
@字号=34
@颜色=#141518
@行距=1.25
@描边=2
@白底透明度=100
夜明け：新しい旅が始まる。
```

構造化 BCS ブロックではコロンも本文の一部です。前後の文をそのまま保持し、コロンの前を話者名として削除しません。作品に表示しない話者ラベルは追加しないでください。
