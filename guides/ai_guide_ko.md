# 랑바이 만화 자막 공방: AI 정밀 자막 스크립트 생성 안내 (기본 BCS v3)

## 기본 제작 규약: 원본 이미지를 읽을 수 있는 모든 AI

앱에서 내보낸 완전한 BCS 템플릿, 확인된 이미지 순서, 최종 원본 해상도 이미지를 사용합니다. 줄거리, 인물 말투, 고정 HEX 글자 색상, 사용 가능한 글꼴을 제공합니다. 썸네일로 좌표·크기·글꼴 소재 ID를 추측하지 않습니다. UTF-8 일반 텍스트만 출력하고 Markdown 코드 울타리, 설명, JSON, 감사 파일은 출력하지 않습니다.

처음 세 줄은 `@格式=BCS顺序字幕脚本`, `@版本=3`, `@坐标单位=px`입니다. 자막 없는 이미지도 포함해 모든 이미지 구간과 기존 ID를 유지합니다. 기본 필드는 `@气泡ID`, `@矩形`, `@尾巴`, `@气泡`, `@字体`, `@字号`, `@颜色`, `@行距`, `@描边`, `@白底透明度`이며 프로토콜 이름과 값은 중국어 그대로 둡니다.

- `@字号模式=固定`은 지정한 글자 크기를 줄이지 않습니다. `自动适配`에서만 자동 축소를 허용합니다. 기존 v1/v2는 자동 맞춤을 유지합니다. 고정 글자는 편집 사각형 밖으로 나갈 수 있으며 경고를 표시하고 전체 이미지 경계만 자릅니다. 안전한 사각형 확대, 대사 축약, 수동 크기 축소 또는 자동 맞춤을 선택하세요.
- `@文字描边=0–20`, `@文字描边颜色=#HEX`는 글자 외곽선입니다. `@描边=0–20`은 말풍선 테두리만 조절하며 0이면 그리지 않습니다. `@气泡=纯文字`는 배경·테두리·꼬리가 없지만 글자 외곽선은 사용할 수 있습니다.
- `@字距=-10–50`, `@对齐=左对齐|居中|右对齐`는 자간과 정렬입니다. 글자 크기는 8–200, 줄 간격은 0.8–3, 흰 배경 불투명도는 0–100입니다. 길이는 미리보기 화면이 아닌 원본 이미지 픽셀이며 소수 좌표를 허용합니다.
- 선택 사항인 `@字体素材ID`, `@样式ID`는 제공된 글꼴 소재와 연결 스타일을 가리킵니다. 알려진 ID만 유지하고 만들지 않습니다. 실행 시 해시 별명만 쓰지 말고 읽을 수 있는 글꼴 표시 이름을 씁니다.
- 각 말풍선의 마지막 필드는 `@正文行数=N`입니다. 바로 뒤 N줄은 실제 작품 본문으로 읽습니다. 빈 줄, 앞뒤 공백, `@`, `#`, `[图片 …]`, 콜론도 그대로 보존합니다. 본문 빈 줄은 포함하고 블록 구분 빈 줄은 제외합니다. N=0은 빈 말풍선을 유지하며 잘못되거나 부족한 줄 수는 적용을 막습니다.

새 글자의 기본값은 고정 크기, 글자 외곽선 0／검정, 자간 0／가운데입니다. 이야기 연속성, 말투, 발화 대상, 읽는 순서를 유지하고 얼굴·손·소품·동작·기존 글자를 가리지 않습니다. 출력 전 이미지 실제 크기, 개수, 사각형, 고유 ID, 본문 줄 수를 내부 확인합니다.

```text
@格式=BCS顺序字幕脚本
@版本=3
@坐标单位=px

[图片 1]
@原文件名=example.png
@原图尺寸=1080x1920

@气泡ID=p1-b1
@矩形=80,100,500,180
@尾巴=右下
@气泡=纯文字
@字体=Noto Sans SC
@字号=40
@颜色=#141518
@行距=1.25
@描边=0
@白底透明度=100
@字号模式=固定
@文字描边=2
@文字描边颜色=#FFFFFF
@字距=0
@对齐=居中
@正文行数=1
콜론도 본문입니다: 문장 전체를 보존하세요.
```

BCS는 이미지나 글꼴 파일을 포함하지 않습니다. 다른 기기로 프로젝트 또는 필요한 소재를 전달하세요. 글꼴 없음, 글리프 없음, 해시 불일치는 명확히 알립니다. 미리보기와 PNG 내보내기는 같은 글자 배치를 사용하며 본문을 생략하지 않습니다.

## 별도 호환 작업: 아래 기존 프롬프트는 BCS v2 유지

v2에는 고정 크기, 글자 외곽선, 자간／정렬, 글꼴 소재 ID, 연결 스타일이 없습니다. 빈 말풍선, 본문 빈 줄, 앞뒤 공백, 예약 기호로 시작하는 본문도 정확하게 왕복하지 못합니다. 필요한 경우 v3를 사용하고 기존 프롬프트의 버전 숫자만 바꾸지 마세요.

이 안내서는 이미지를 읽을 수 있는 모든 AI가 앱에 바로 가져올 수 있는 `BCS顺序字幕脚本 v2`를 만들도록 하기 위한 것입니다. 앱은 확인된 이미지 순서로만 매칭하며 파일명으로 재정렬하지 않습니다.

## 권장 작업 순서

1. 최종 원본 해상도 이미지를 가져오고 순서를 확인합니다.
2. 자막에서 **현재 템플릿 내보내기**를 선택합니다. 템플릿에는 정확한 순서, 원본 파일명 힌트, 실제 픽셀 크기, 기존 말풍선 ID가 포함됩니다.
3. 템플릿, 최종 이미지, 전체 줄거리, 인물 말투, 고정 글자 색상표와 아래 프롬프트를 AI에 제공합니다.
4. Markdown, 설명, JSON, 미리보기, 감사 보고서 없이 일반 텍스트만 반환하도록 요구합니다.
5. UTF-8 `.txt`로 저장하고 가져온 뒤 매칭 검사를 실행하고 **적용 및 자동 배치**를 누릅니다.

정확한 좌표에는 최종 원본 크기 이미지가 반드시 필요합니다. 줄거리, 썸네일, 초안, 콘티 설명, 예상 크기만으로는 신뢰할 수 있는 위치를 정할 수 없습니다. 모든 이미지, 순서, 실제 크기를 읽을 수 없다면 AI는 추측하지 말고 짧고 구체적인 질문 하나만 해야 합니다.

## 번역하면 안 되는 BCS 용어

BCS 필드명과 열거 값은 프로토콜 토큰입니다. 본문이 한국어여도 아래 값은 그대로 유지합니다.

- 헤더: `@格式=BCS顺序字幕脚本`, `@版本=2`, `@坐标单位=px`
- 이미지: `[图片 N]`, `@原文件名`, `@原图尺寸`
- 말풍선: `@气泡ID`, `@矩形`, `@尾巴`, `@气泡`, `@字体`, `@字号`, `@颜色`, `@行距`, `@描边`, `@白底透明度`
- 종류: `对话气泡`, `心理气泡`, `旁白框`, `耳语气泡`, `惊喊气泡`, `纯文字`
- 꼬리: `左上`, `右上`, `左下`, `右下`

말풍선 본문은 한국어를 포함한 모든 언어를 사용할 수 있습니다.

## 첫 대화에서 사용할 고정 프롬프트

```text
당신은 전문 만화 대사 편집자, 말풍선 레터링 담당자이며 “랑바이 만화 자막 공방”용 BCS顺序字幕脚本 v2 생성기입니다.

사용자가 올바른 순서로 업로드한 최종 이미지, 전체 이야기, 인물 말투, 고정 글자 색상표를 바탕으로 앱에 바로 가져올 수 있는 BCS 스크립트를 생성하세요.

[작업 모드]
빠른 제작 모드를 사용합니다. 이미지 인식, 대사 작성, 말풍선 분류, 좌표 계산, 형식 검사는 내부에서 수행하되 분석 과정은 출력하지 않습니다. 설명, 창작 보고서, JSON, 캐릭터 카드, 미리보기, 감사 기록, 개선 제안을 출력하지 않습니다. 모든 최종 이미지, 순서, 실제 픽셀 크기를 확인할 수 있으면 질문하지 말고 결과를 출력합니다. 하나라도 확인할 수 없으면 짧고 구체적인 질문 하나만 하고 크기나 좌표를 추측하지 않습니다. 공식 좌표는 최종 원본 이미지에만 근거하며 초안, 썸네일, 콘티, 아직 생성되지 않은 장면에 근거하지 않습니다.

[이야기 연속성]
전체 이야기, 인물 관계, 갈등 단계, 각 이미지의 서사 역할을 내부에서 이해한 뒤 이미지별 자막을 작성합니다. 각 이미지를 서로 무관한 장면으로 취급하지 않습니다. 인접 장면의 대사는 자연스러운 질문, 대답, 끼어들기, 침묵, 오해, 복선, 회수가 이어지게 합니다. 자막이 없는 이미지도 허용하며 화면을 채우기 위해 억지로 말풍선을 추가하지 않습니다. 표정, 동작, 거리, 시선, 감정과 맞추고 이야기와 이미지에 없는 사건을 만들지 않습니다.

[대사]
인물의 신분과 상황에 맞고 실제로 말할 수 있는 자연스러운 대사를 씁니다. 인물은 눈앞의 사람, 행동, 문제, 판단, 선택을 말하며 작가 대신 세계관이나 주제를 낭독하지 않습니다. 유머는 성격 차이, 관계, 오해, 허세, 자조, 말받기, 앞뒤 호응에서 나와야 합니다. 위기, 전쟁, 희생, 슬픔, 중대한 진실, 작별 장면에서는 절제합니다. 인터넷 밈, 홍보 문구, 정돈된 명언, 반복되는 AI식 반전 농담을 남용하지 않습니다. 긴 문장은 고치거나 나누고, 말풍선 하나에는 주된 의도 하나만 담습니다. 외침은 더 짧게 씁니다. 그 상황에서 사람이 자연스럽게 말하지 않을 문장은 다시 씁니다.

[내레이션]
이미지만으로 알 수 없는 시간, 장소 변화, 자원, 전선 변화, 인물이 모르는 정보, 인과관계만 정확하고 간결하게 보충합니다. 보이는 행동을 다른 말로 반복하지 않습니다. 작가 농담, 사물 의인화, 장난스러운 비유, 수사 질문, 반전 농담을 사용하지 않습니다.

[보이는 글자]
본문에는 작품에 실제로 표시할 글자만 넣습니다. 화자 이름, “내레이션:”, “생각:”, 이미지 번호, 컷 번호, 말풍선 종류, 편집 지시를 쓰지 않습니다. 화자는 위치, 스타일, 말투, 고정 글자 색상으로 구분되어야 합니다. 실제 문장에 필요한 콜론과 앞뒤 내용은 모두 그대로 유지합니다.

[말풍선 종류]
`@气泡=` 뒤에는 아래 중국어 프로토콜 값만 사용합니다.
对话气泡 = 일반 대화
心理气泡 = 속마음, 구름형 본체와 원형 점 꼬리
旁白框 = 내레이션, 녹음, 방송, 통신; 보이는 꼬리 없음
耳语气泡 = 속삭임, 약한 목소리, 귓속말
惊喊气泡 = 외침, 놀람, 강한 감정
纯文字 = 이미지 위에 글자만 표시하며 배경, 테두리, 꼬리 없음
`旁白框`과 `纯文字`에도 합법적인 `@尾巴` 값을 하나 넣지만 꼬리는 그리지 않습니다. `纯文字`의 사각형은 글자 배치 영역이며 보이는 상자가 아닙니다. 글꼴, 글자 크기, 색상, 줄 간격은 적용됩니다. `@描边`는 글자 외곽선이 아니라 말풍선 테두리 두께입니다. `@白底透明度`와 함께 값을 유지하고 0으로 바꿀 필요는 없지만 순수 글자 렌더링에는 적용되지 않습니다.

[글자 색상]
같은 인물과 같은 상태에서는 동일한 6자리 HEX 글자 색상을 유지합니다. 내레이션은 지정 색상, 미지정 시 `#141518`을 사용합니다. 상태표에 없는 색을 만들지 않습니다. 색상은 글자에만 적용하며 말풍선은 흰색/연회색 배경과 검은 외곽선을 유지합니다. 순수 글자에는 배경과 테두리를 그리지 않습니다.

[배치]
각 최종 이미지의 실제 픽셀 크기를 읽고 왼쪽 위를 `(0,0)`으로 둡니다. 모든 사각형은 `x>=0`, `y>=0`, `width>0`, `height>0`, `x+width<=이미지 너비`, `y+height<=이미지 높이`를 만족해야 합니다.

얼굴, 눈, 입, 머리 윤곽, 손, 접촉 지점, 시선 끝, 무기, 중요 소품, 핵심 효과, 의상, 시각 중심, 기존 글자를 보호합니다. 하늘, 빈 벽, 정보가 적은 어두운 영역, 바닥 가장자리, 흐린 배경, 반복 무늬 같은 보조 여백을 우선합니다. 가까움보다 안전이 우선입니다. 공간이 부족하면 대사 축약, 사각형 축소, 화자 쪽 안전한 배경으로 이동, 비대사 정보를 旁白框으로 변경, 불필요한 자막 삭제 순으로 처리합니다.

대화와 생각 말풍선은 화자 쪽 또는 인접 영역에 두고 가능하면 화면 세로 중앙선을 넘지 않습니다. 여러 인물이 있으면 각 말풍선을 정확한 인물 가까이에 두며 질문보다 답이 먼저 읽히지 않게 합니다. 기본 읽기 순서는 왼쪽에서 오른쪽, 위에서 아래입니다. 말풍선끼리 겹치지 않게 합니다.

[꼬리]
BCS는 꼬리 끝 좌표를 사용하지 않으며 화살표나 안내선을 추가하지 않습니다. `@尾巴`는 `左上`, `右上`, `左下`, `右下`만 허용됩니다. 대화, 생각, 속삭임, 외침 말풍선은 화자 얼굴과 가장 가까운 말풍선 모서리를 선택합니다. 다른 인물, 소품, 화면 밖을 가리키면 안 되며 긴 꼬리로 화면을 가로지르지 않습니다.

[기본 스타일]
@字体=Noto Sans SC
@字号=34
@行距=1.25
@描边=2
@白底透明度=100

@版本=2

[图片 1]

@原图尺寸=actual-widthxactual-height

실제 표시할 본문

[출력]
```

## 가져오기 전 확인

- `[图片 N]` 구간 수가 앱의 이미지 수와 정확히 같습니다.
- 모든 `@原图尺寸`가 내보낸 템플릿과 같습니다.
- 이미지 구간이 연속되고 확인한 순서를 유지합니다.
- 모든 ID가 고유하고 모든 사각형이 이미지 경계 안에 있습니다.
- BCS 필드명과 열거 값은 정확한 중국어 토큰을 유지합니다.
- UTF-8 일반 텍스트이며 Markdown이나 AI 설명이 없습니다.

## 말풍선 없는 글자

**글자 추가**를 사용하거나 기존 말풍선 종류를 순수 글자로 바꿉니다. 배치 영역 이동과 크기 조절, 글꼴·글자 크기·색상·줄 간격 변경, 프로젝트 저장, BCS 가져오기와 내보내기가 가능합니다. 선택할 때 표시되는 조절 상자는 편집 보조 도구이며 내보낸 이미지에는 포함되지 않습니다.

AI에 어떤 자막을 `@气泡=纯文字`로 만들지 알려 주세요. 배경과의 대비를 확보하고 얼굴이나 중요한 물건을 가리지 않는 안전한 영역에 배치합니다. 여러 이미지 프로젝트는 모든 이미지 구간을 유지해야 합니다. 아래는 한 이미지의 완전한 예시이며 파일명과 크기를 실제 값으로 바꿔야 합니다.

```text
@格式=BCS顺序字幕脚本
@版本=2
@坐标单位=px

[图片 1]
@原文件名=001.png
@原图尺寸=1080x1920

@气泡ID=p1-b1
@矩形=70,90,500,180
@尾巴=右下
@气泡=纯文字
@字体=Noto Sans SC
@字号=34
@颜色=#141518
@行距=1.25
@描边=2
@白底透明度=100
새벽: 새로운 여정이 시작된다.
```

구조화된 BCS 블록에서 콜론은 본문의 일부입니다. 앞뒤 문장을 그대로 유지하며 콜론 앞을 화자 이름으로 처리해 삭제하지 않습니다. 실제 작품에 표시하지 않는 화자 라벨은 추가하지 마세요.
